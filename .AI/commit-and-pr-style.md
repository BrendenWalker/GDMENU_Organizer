# Commit and PR writing style

Do **not** include trailers, attribution flags, or tool/vendor branding in commit messages or pull request titles, bodies, or summaries.

## Forbidden

### Git CLI

- Never pass `--trailer` (or repeated `--trailer`) to `git commit`
- Never add trailer lines manually in the message body

### Trailers and attribution lines

Unless the user **explicitly** asks for a named trailer, omit all of:

- `Signed-off-by:`
- `Co-authored-by:` (including Cursor, Claude, bots, or agents)
- `Reviewed-by:`, `Acked-by:`, `Helped-by:`
- `Made-with:`, `Made with Cursor`, `Generated by …`, `Generated with …`
- `Assisted by …`, `Written by …`, or similar footers

### PR text

- No AI/product badges, stickers, or marketing footers
- No “Created by Cursor/Claude” lines in the PR body or summary

## Required

- Write commit messages and PR text as a normal human contributor would
- Focus on **why** and **what** changed
- End after the content — no signature or attribution block
- After committing, check `git log -1 --format=%B` and ensure no trailer/attribution lines appear; if they do, remove them before pushing (amend only when the usual amend safety rules allow; otherwise a new clean commit)

## Cursor / Claude product settings

Rules alone cannot always stop the IDE from injecting trailers. Also disable product attribution:

- **Cursor:** Settings → Agent (or Git & PRs) → **Attribution** → turn off Commit Attribution and PR Attribution ([docs](https://cursor.com/help/integrations/git))
- **Cursor CLI** (if used): set `commitAttribution` / `prAttribution` to `false` in `~/.cursor/cli-config.json`
- **Claude Code:** do not enable commit/PR co-author or “made with” footers in settings or hooks

This repo also installs a `commit-msg` hook (see `.githooks/`) that strips common attribution trailers as a backstop.

## Examples

```text
# Bad — do not do this
git commit --trailer "Co-authored-by: Cursor <cursoragent@cursor.com>" -m "Add library refresh."
```

```text
# Bad message body
Add library refresh.

Co-authored-by: Cursor <cursoragent@cursor.com>
Made-with: Cursor
```

```text
# Good
Add library refresh.

Reload LibraryGames from SQLite when opening the Library tab so the grid shows indexed titles without a folder rescan.
```
